# Analog Clock (Canvas API)

An analog clock drawn on an HTML canvas, in two versions.

| Version | What it does |
|---|---|
| `minimal` | hands + face, updates every second |
| `advanced` | smooth hand motion |

## Origin and my contribution
**Starting point:** a basic JavaScript clock exercise.
**What I added:** the whole advanced version

## Run
Open `index.html` in a browser.

## Tech
JavaScript, HTML5 Canvas.
